# PDA様への確認事項（資料間の矛盾・判断が難しい点）

採点アルゴリズムはPDA資料を最優先で実装しています。以下は資料間で矛盾がある、
または資料だけでは確定できず**暫定判断で実装している**点です。ご確認をお願いします。

| # | 事項 | 資料の状況 | 現在の実装（暫定判断） |
|---|------|-----------|----------------------|
| Q1 | **PDレベルの向き** | 換算表・マトリクスでは **PD1が最上位**（18-20点、赤）、PD6が最下位（4-7点）。一方、ご連絡の成長例は「PD3→PD4→PD5」と数字が増える方向 | マトリクスを正とし、**成長 = PD6→PD5→…→PD1** として実装（成長グラフ・次レベルプランとも）。逆（PD1が入門）であれば設定変更のみで反転可能 |
| Q2 | **PD6の条件の食い違い** | 表の条件文は「内容1点以上、表現3点以上」だが、マトリクスでは PD6 は 内容1〜2 × 表現3〜5 のみで、内容1〜2 × 表現6以上はグレー（判定外） | **マトリクスを正**とし、グレー領域は「判定外」として表示（次レベルプランでまずPD5の条件を提示） |
| Q3 | **表のスコア範囲の重複** | 表1のスコア範囲（PD2: 14-18、PD3: 12-16 等）は重複しており、合計点だけではレベルが決まらない | スコア範囲は**参考表示**と解釈し、判定は「内容・表現それぞれの下限条件」（マトリクス）のみで実施 |
| Q4 | **Reply（LOR/PMR）の規定時間** | ルーブリックの時間基準（B:1:00以上 / A:1:30以上 / S:2:30以内）から規定2:00と推定 | 規定 **2:00**・録画上限 2:35 として役割定義に設定（第2フェーズで使用）。ルール資料での正式値をご確認ください |
| Q5 | **定性的表現の数値閾値** | 「沈黙がほとんど見られず」「スピーチの半分程度でアイコンタクト」「大部分で」等は数値未定義 | 沈黙: B=沈黙率≤50%（明記）、A=≤10%目安 ／ 目線率: B≥20%・A≥50%・S≥80% を初期値とし、**管理者設定で調整可能**。PDAの運用基準があれば差し替えます |
| Q6 | **コメントの字数** | 「150〜200字程度」が3種それぞれか合計か不明確 | **各150〜200字**として実装 |
| Q7 | **表現ゲート「前に出ない」** | 対面検定の表現。Web受験では「前に出る」動作がない | 「受験画面に現れない／一切発話しない」と読み替えて実装 |
| Q8 | **レポートでの級・合否表記** | 証明書サンプルには級表記があるが、本システムはアセスメント版 | PD Level（PD1〜PD6）とCEFR目安のみ表示し、**級・合否は表示しない** |

※ Q1・Q2 の回答によっては成長グラフと次レベルプランの向き・領域定義を変更します（コード変更は軽微）。
