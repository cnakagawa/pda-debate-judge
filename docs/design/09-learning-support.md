# 9. 学習支援設計（Learning Support Design）

本システムは「採点システム」ではなく**学習支援システム**である。
受験者が結果を見て終わりではなく、**なぜその評価になったのか・何を練習すれば次のレベルに上がれるのか**まで
到達できることを、システムの中核要件とする。

## 9.1 設計思想

1. **透明性** — 全評価はルーブリック詳細項目の充足/未充足として説明され、受験者本人が根拠（スピーチからの引用つき）を見られる。
2. **行動可能性** — 改善点は「頑張りましょう」ではなく、ルーブリック原文の未充足項目とスピーチシート上の位置として具体的に示す。
3. **成長の可視化** — 受験履歴を保存し、PDレベル・内容/表現スコアの推移をグラフで示す。
4. **ルーブリック非逸脱** — 学習アドバイスも**ルーブリック詳細項目そのもの**から生成する。AI独自の練習基準は作らない。

## 9.2 受験者に提示する4層のフィードバック

| 層 | 内容 | 生成方法 |
|----|------|----------|
| ① 結果 | Matter/Manner/Total/PD Level/8項目のS/A/B/C | RubricEngine（決定的） |
| ② 根拠 | 各評価項目について、ルーブリック詳細項目ごとの充足/未充足・判定理由・スピーチ引用 | 保存済みの判定結果をそのまま開示（管理者画面と同一データの受験者向け表示） |
| ③ スピーチシート・チェック | スピーチシートの構成要素（PM: 定義/Point1/Point2/Point1詳細、LO: 反論/Point1/Point2/Point1詳細）ごとの有無と該当箇所引用 | LLM構造抽出結果を evaluation に永続保存し表示 |
| ④ 次レベルプラン | 次のPDレベルに必要な内容・表現の点数と、その到達に必要な未充足詳細項目のリスト | **NextLevelPlan（決定的アルゴリズム、9.3）** |

コメント3種（Good/Improvement/Overall）は④のプランを入力として生成し、
「次のレベルに上がるために効果が大きい練習」を必ず含める。

## 9.3 NextLevelPlan アルゴリズム（決定的・AI不使用）

PDレベルマトリクス（PD1が最上位）から逆算する。

```
レベル到達条件（PDA提供マトリクス）:
  PD5: 内容≥3 かつ 表現≥3
  PD4: 内容≥5 かつ 表現≥5
  PD3: 内容≥6 かつ 表現≥6
  PD2: 内容≥7 かつ 表現≥7
  PD1: 内容≥9 かつ 表現≥9

1. 目標レベル = 上記ラダーのうち、まだ条件を満たしていない最初のレベル
   （PD6は入口領域であり目標としては扱わない。PD1到達済みなら目標なし＝維持）
2. 各カテゴリの不足点 gap = max(0, 必要点 − 現在点)
3. gap がある各カテゴリについて、ルーブリックの帯域規則から「点を上げる最短経路」を導出:
   - 目標 ≤5点: 未充足のB帯詳細項目（B充足項目数が 3→4点、4→5点）
   - 目標 = 6点: 未充足のB帯 + A帯詳細項目（4項目すべてのA充足で6点）
   - 目標 ≥7点: 上記に加え、「特に評価できる」に最も近い項目のS帯詳細項目
     （不足数が少ない項目から優先）
4. 推奨リストは {評価項目, 帯域, ルーブリック原文, 効果（例: B充足4項目で5点）} の形で出力
```

- 出力される「練習すべきこと」はすべて**ルーブリック詳細項目の原文**である（AI独自基準の混入を構造的に防止）。
- POI等、Web受験版で判定対象外の項目は推奨に含めない。
- 判定外（グレー領域）の場合は、まず PD5 の条件（内容3・表現3）を目標とする。

## 9.4 成長履歴の可視化

- 全受験は既存設計どおり永続保存（assessments / evaluations）。
- Assessment History 画面に**成長グラフ**を表示:
  - 横軸: 受験日（採点完了した受験のみ）
  - 縦軸: 内容・表現スコア（0-10）の2系列 + 各受験時点のPDレベルをバッジ表示
  - 例: PD5 → PD4 → PD3 と上位レベルへ向かう推移が一目で分かる
- レポート画面にも「前回からの変化」（スコア差分・レベル変動）を表示（同一Roleの直近受験と比較）。
- 第2フェーズ: 項目別（8項目）の推移、練習推奨項目の達成トラッキング。

## 9.5 データ設計への反映

- `evaluations.structure` (jsonb) — スピーチシート構造抽出結果を永続保存（③の表示元。修正時は前世代から引継ぎ）。
- NextLevelPlan は保存せず**表示時に決定的に再計算**する（評価修正後も常に最新の評価と整合するため）。
- 成長グラフは既存の evaluations（is_current）から算出。追加テーブル不要。

## 9.6 画面への反映（03-screens への追補）

- **レポート画面**に追加:
  1. 「評価の根拠を見る」 — 8項目それぞれの詳細項目チェックリスト（✓/✗・判定理由・引用）
  2. 「スピーチシート・チェック」 — 構成要素の有無と該当引用
  3. 「次のレベルへのプラン」 — 目標レベル・必要点・練習すべきルーブリック項目
  4. 「前回からの変化」
- **History 画面**に成長グラフを追加。
- PDF レポートに「Next Step」欄（目標レベルと練習項目上位3件）を追加。
