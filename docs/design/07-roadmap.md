# 7. 開発ロードマップ

## Phase 1 — MVP（Web受験版）: 約10週間

| 週 | マイルストーン | 内容 |
|----|----------------|------|
| 1–2 | **基盤** | リポジトリ再構成（legacy退避）・Next.js/Prisma/pg-boss/Docker/CI・認証・DBマイグレーション・設定マスタ |
| 2–3 | **ルーブリックエンジン** | ルーブリックJSON化（Excel転記）・RubricEngine実装・**全帯域の単体テスト**（0〜10点の全パターン網羅）・PD Level暫定マスタ |
| 3–5 | **採点パイプライン** | 録画アップロード→ffmpeg→STT→計測→Vision→LLM判定→コメント→PDF→cleanup。管理者向け失敗ジョブ画面 |
| 5–7 | **PM Assessment 一気通貫** | 受験ウィザード（論題→準備5分→録画3分→採点→レポート表示/PDF）・履歴画面 |
| 7–8 | **LO Assessment** | PMスピーチ生成+自己検査+TTS・LO受験フロー・LO用判定（反論の対応関係） |
| 8–9 | **管理者画面** | 論題管理・Assessment履歴・AI評価確認・評価修正（再計算）・録画保存設定・PDF再発行 |
| 9–10 | **品質確認・調整** | ゴールデンセットでの採点精度検証（PDA監修）・閾値較正・E2Eテスト・負荷試験・セキュリティ点検・パイロット受験会 |

**Phase 1 完了条件（Definition of Done）**
- PM/LO の受験がPCブラウザで一気通貫に完了し、PD Assessment Report（画面+PDF）が出力される
- 全評価項目に判定根拠（引用付き）が保存され、管理者が修正→再計算→PDF再発行できる
- 録画が採点後に自動削除される（設定で保持に切替可能）
- RubricEngine 単体テスト100%パス・ゴールデンセットで人間ジャッジとの項目グレード一致率を計測済み

## Phase 2 — 精度向上と拡張: 約8〜12週間

- **Zoom連携**（Meeting SDK / クラウド録画 + Webhook → 既存パイプラインへ接続。legacyのPOIイベント化ノウハウを移植し、POI関連評価項目を有効化）
- **日本語ディベート対応**（論題・生成スピーチ・判定プロンプト・コメントのja版、STT言語切替）
- **残り役割の追加**：MG / MO / LOR / PMR（RoleSpec追加 + 先行スピーチ複数生成。Reply用ルーブリック差分は実装済み）
- 採点精度改善サイクル（管理者修正データの分析→プロンプト改訂→ゴールデン回帰）
- スコア推移グラフ・学習アドバイスの強化、英語UI

## Phase 3 — プラットフォーム化: 継続

- Microsoft Teams / Google Meet 連携
- 団体（学校・教室）管理：クラス単位の受験管理・教員閲覧・一括レポート
- チーム戦（複数話者）のアセスメント、POIを含む試合全体評価（legacy資産の本統合）
- 外部LMS連携・API公開

## 運用体制（Phase 1 から実施）

- ルーブリック・プロンプト・PD Level表の変更はすべてバージョン管理し、変更時はゴールデン回帰を必須化
- 依存パッケージの定期更新（Renovate）・四半期ごとのセキュリティレビュー
- DBの日次バックアップ・リストア手順書・障害時ランブック整備
